# 墨锭试磨室

运行：

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/ink-stick-testing.json`。

## 环境巡检流程

巡检单与建档、试磨流程打通：

- **建档**：同时记首张巡检单（库位、温度、湿度、外观、巡检人）。
- **试磨前巡检**：见**霉点或软边**即判「待复验」，墨锭自动**隔离**、暂停试磨。
- **每锭只留一张未复验单**：再次巡检仍异常，旧单立即失效、由新单顶替；隔离中不能另开一张“正常”单绕过复验。
- **复验**：必须**换人**（复验人不得与原巡检人相同）；隔满 **12 小时**做两次，两次湿度均**低于 65%** 且外观正常，才恢复试磨。中途不合格则两次计数清零重来。
- **结论失效**：改库位、改巡检值（温度/湿度/外观）都会让原结论失效，需重新巡检；**旧单保留可查**。
- **列表筛选**：巡检单可按「正常 / 待复验 / 已失效」筛选；墨锭状态含「隔离」。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `lib/judgment.js` | 判定业务：巡检结论、隔离与复验规则、试磨放行（纯逻辑，不读写文件） |
| `lib/storage.js`  | 存储业务：JSON 档案读写、巡检单与墨锭查询、种子数据 |
| `lib/page.js`     | 页面业务：建档/巡检/复验/试磨录入界面与列表筛选 |
| `server.js`       | HTTP 路由，串联上述三个业务文件 |
